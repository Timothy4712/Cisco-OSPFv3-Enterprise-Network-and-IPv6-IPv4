# Cisco-OSPFv3-Enterprise-Network-and-IPv6-IPv4
This project uses hierarchical 3-Layer Enterprise Network architecture (Core, Distribution, Access) along side with OSPFv3 routing mechanism. The network is both IPv4/6 compatible.

**Network Topology Specifications:**
-Core Layer: 2 x Core Routers providing high-speed backbone routing.
-Distribution Layer: 2 x Multilayer Switches handling VLAN routing, Inter-VLAN communication, and summarisation.
-Access Layer: 4 Access Switches connecting end-user devices (PCs, Phones).
OSPFv3 Areas:
Area 0 (Backbone): Connects Core and Distribution routers.
Area 1: Connects Management department
Area 2: Connects Engineering department
